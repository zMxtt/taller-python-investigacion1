# Investigación sobre GitHub Projects

# 1. ¿Qué son los GitHub Projects y cómo ayudan en la gestión de proyectos?

GitHub Projects es una herramienta de GitHub que permite organizar tareas, issues y pull requests mediante tableros visuales.

Ayudan en la gestión de proyectos porque facilitan el seguimiento del progreso, la organización del trabajo y la colaboración entre desarrolladores.

---

# 2. ¿Qué diferencia hay entre Projects y un tablero Kanban tradicional?

La diferencia es que GitHub Projects está integrado directamente con los repositorios, issues y pull requests de GitHub.

Un tablero Kanban tradicional normalmente requiere herramientas externas y no tiene integración automática con el código fuente.

---

# 3. ¿Cómo se pueden automatizar las tareas en GitHub Projects?

Las tareas se pueden automatizar usando reglas y flujos automáticos de GitHub.

Por ejemplo:

- Mover un issue a "Done" cuando se cierre.
- Agregar automáticamente nuevos issues al tablero.
- Cambiar el estado de una tarea cuando se crea un Pull Request relacionado.
